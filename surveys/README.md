# Surveys

Cross-cutting catalogs that map a landscape of standards or approaches, with gap analysis and decision
guidance. Unlike `/domains` (thin problem indexes) and `/approaches` (v2 use-case cards), a survey is a
reference catalog. Keep each survey scoped to one landscape and link out to the relevant use cases,
patterns, and vendors rather than duplicating them.
